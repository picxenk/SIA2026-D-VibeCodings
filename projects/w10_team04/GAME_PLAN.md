# 슈와 몽이: 별빛 수호대 — 게임 기획서

> 작은 2D 협동 RPG 미니게임 / 웹(HTML5) / 플래시 게임 감성

- 문서 버전: v0.1 (초안)
- 작성일: 2026-11-10
- 장르: 2D 협동 퍼즐 어드벤처 + 초경량 RPG
- 플랫폼: PC 웹 브라우저 (키보드)
- 플레이 타임: 1회차 10~15분
- 개발 규모: 1인, 약 5일 (프로토타입 기준)

---

## 1. 한 줄 소개

**"슈"와 새 친구 "몽이"가 서로 다른 능력을 써서 별빛 조각을 되찾는, 두 캐릭터 전환형 초간단 2D RPG.**

- 슈 게임 시리즈의 팬 게임에서 출발하되, **원작 캐릭터 1명(슈) + 신규 오리지널 캐릭터 1명(몽이)** 구성
- 《불과물의 신전(Fireboy & Watergirl)》처럼 **두 캐릭터의 능력 차이를 이용한 협동 퍼즐**이 핵심
- 전투/성장은 최소한으로, 퍼즐과 짧은 스토리에 집중

---

## 2. 목표와 성공 기준

### 2.1 프로젝트 목표
1. 웹 브라우저에서 바로 실행되는 **설치 없는 미니게임** 완성
2. 캐릭터 전환만으로 **"혼자서 2인 협동"**을 느끼게 하는 재미 검증
3. 플래시 게임처럼 **귀엽고 단순한 그래픽**으로 짧은 시간에 완성

### 2.2 성공 기준 (MVP 완료 조건)
- [ ] 타이틀 → 스테이지 3개 → 엔딩까지 끊김 없이 진행된다.
- [ ] 슈/몽이 전환이 즉시 되고, 두 캐릭터의 능력 없이는 못 지나가는 구간이 최소 2개 이상 있다.
- [ ] 체력, 코인, 회복 아이템, 보스전이 동작한다.
- [ ] 키보드만으로 모든 조작이 가능하고, 조작법이 화면에 안내된다.
- [ ] 처음 하는 사람이 설명 없이 1분 안에 이동/전환을 익힌다.
- [ ] 새로고침해도 처음부터 정상 플레이된다(세이브는 선택 기능).

### 2.3 이번에 하지 않을 것 (Non-goals)
- 멀티플레이 네트워크, 모바일 터치, 세이브 슬롯
- 복잡한 스킬 트리, 인벤토리, 대화 분기
- 고해상도 일러스트, 풀 보이스, BGM 작곡
- 상점/결제/배포 플랫폼 연동

## 3. 세계관과 스토리

### 3.1 배경
별빛이 사라진 밤, 마을의 별등(별을 밝히는 등)이 하나둘 꺼져 간다.
슈는 마지막 별등을 지키기 위해 길을 떠나고, 그 앞에 별빛 조각에서 태어난 작은 정령 **몽이**가 나타난다.
둘은 흩어진 별빛 조각 3개를 모아 마을의 별등을 다시 밝히기로 한다.

### 3.2 스토리 흐름
| 순서 | 장소 | 목표 | 감정선 |
|---|---|---|---|
| 오프닝 | 마을 | 별등이 꺼지는 사건 목격 | 불안 |
| 튜토리얼 | 별빛 숲 입구 | 몽이와 만나고 협동 익히기 | 설렘 |
| 스테이지 1 | 흔들다리 협곡 | 첫 별빛 조각 회수 | 자신감 |
| 스테이지 2 | 그림자 동굴 | 두 번째 조각, 몽이의 빛 사용 | 긴장 |
| 보스 | 별등 광장 | 그림자 정령 진압, 마지막 조각 | 결의 |
| 엔딩 | 마을 | 별등 점등, 짧은 엔딩 카드 | 따뜻함 |

스토리는 **스테이지 시작/종료 시 1~2줄 대사 카드**로만 전달한다. 컷신은 없다.

## 4. 캐릭터

### 4.1 슈 (플레이어 1, 원작 캐릭터)
- 역할: **힘과 용기** — 직접 부딪히고 밀어내는 쪽
- 능력
  - 무거운 상자 밀기/끌기
  - 짧은 근접 공격(장난감 망치, 쿨타임 0.5초)
  - 체력 5 (몽이보다 단단함)
- 약점: 좁은 틈 통과 불가, 어둠 속 시야 좁음

### 4.2 몽이 (플레이어 2, 신규 캐릭터)
- 역할: **빛과 민첩** — 길을 열고 위험을 알리는 쪽
- 외형: 별 모양 머리의 작은 정령, 반투명 발광. 몸통은 동그란 솜사탕 형태
- 능력
  - 좁은 틈(1칸) 통과
  - 2단 점프 + 짧은 활공
  - 주변을 밝히는 빛(어둠 구간 시야 확보, 그림자 적 약화)
  - 체력 3 (대신 피격 판정이 작음)
- 약점: 상자 밀기 불가, 근접 공격력 낮음

### 4.3 능력 대비표
| 상황 | 슈 | 몽이 |
|---|---|---|
| 무거운 상자 | O | X |
| 좁은 틈 | X | O |
| 높은 곳 | △ (1단 점프) | O (2단+활공) |
| 어둠 속 시야 | X | O |
| 적 제압 | O | △ (빛으로 경직) |
| 체력 | 5 | 3 |

> 두 캐릭터 모두 **죽으면 스테이지 처음부터**가 아니라, 마지막 체크포인트에서 부활한다. (좌절 방지)

## 5. 핵심 게임플레이

### 5.1 기본 구조: "혼자 하는 2인 협동"
- 한 번에 한 캐릭터만 조작한다.
- `Tab`(또는 `Q`)으로 조작 캐릭터를 즉시 전환한다.
- 조작하지 않는 캐릭터는 **제자리에 대기**한다. (따라오기 AI는 만들지 않는다 — 퍼즐이 단순해짐)
- 전환 시 카메라는 조작 캐릭터를 부드럽게 따라간다. 두 캐릭터가 너무 멀어지면 화면 밖 표시(화살표)를 띄운다.

### 5.2 게임 루프
```
탐색 → 퍼즐 발견 → 캐릭터 전환 → 협동으로 길 열기
     → 적/함정 회피 or 제압 → 별빛 조각 획득 → 다음 구역
```

### 5.3 RPG 요소 (초경량)
- **체력**: 하트 5칸(슈) / 3칸(몽이). 피격 시 1칸 감소, 0이면 체크포인트 부활.
- **코인**: 스테이지에 20~30개. 100개마다 하트 1칸 최대치 증가(최대 7).
- **회복 아이템**: 별사탕(하트 1 회복). 스테이지당 2개.
- **성장 없음**: 레벨/스탯 없이 아이템과 퍼즐 해결이 전부. (범위 축소)

### 5.4 전투
- 슈: 근접 공격 1종. 적과 접촉해도 피해.
- 몽이: 공격 대신 **빛 폭발(쿨타임 3초)** — 주변 적 경직 + 어둠 제거.
- 적은 2종만
  - **그림자 슬라임**: 좌우 왕복, 접촉 피해, 슈 2방 / 몽이 빛 2방
  - **박쥐**: 위아래로 흔들며 접근, 몽이 빛에 경직
- 보스: **그림자 정령** — 패턴 2개(돌진, 그림자탄 3발). 슈로 별등을 3회 공격하면 클리어.

### 5.5 실패와 재시작
- 낙사/체력 0 → 0.8초 페이드 후 체크포인트 부활, 코인 절반 유지
- 체크포인트: 스테이지당 2개 (입구, 중간)
- ESC → 일시정지(재개/스테이지 재시작/타이틀)

## 6. 스테이지 구성

각 스테이지는 **1~2분 내외**, 총 3스테이지 + 보스.

### 튜토리얼: 별빛 숲 입구
- 이동, 점프, 전환 학습
- 슈로 상자 밀어 발판 만들기 → 몽이로 좁은 틈 통과 → 문 열기
- 적 없음, 코인 5개

### 스테이지 1: 흔들다리 협곡
- 핵심 기믹: **상자 + 좁은 틈 + 낙사**
- 슈가 상자를 밀어 발판을 만들고, 몽이가 스위치를 눌러 다리를 내림
- 그림자 슬라임 2마리
- 별빛 조각 1 획득, 코인 25개

### 스테이지 2: 그림자 동굴
- 핵심 기믹: **어둠 + 몽이의 빛**
- 몽이로만 지나갈 수 있는 틈, 빛으로만 보이는 숨은 발판
- 박쥐 2마리, 슬라임 1마리
- 별빛 조각 2 획득, 코인 25개

### 보스: 별등 광장
- 그림자 정령과 2페이즈 전투
- 페이즈 1: 돌진 회피 → 슈 근접
- 페이즈 2: 그림자탄 3발 → 몽이 빛으로 탄 제거 → 슈 마무리
- 클리어 시 별등 점등 연출 + 엔딩 카드

### 레벨 데이터 예시 (ASCII 타일맵)
```
# = 벽, . = 빈칸, P = 시작, S = 슈, M = 몽이
B = 상자, ^ = 가시, o = 코인, * = 별빛 조각, D = 문
####################
#..................#
#..S....B....o.o...#
#..###..###....D...#
#....M.......*..#..#
####################
```
- 레벨은 문자열 배열로 작성하고, 타일 16px 기준으로 렌더링한다.
- 에디터는 만들지 않는다. 코드 안에서 직접 수정한다.

## 7. 조작

| 동작 | 키 |
|---|---|
| 이동 | ← → (또는 A D) |
| 점프 | Space (또는 ↑ / W) |
| 공격 / 빛 | Z (또는 J) |
| 캐릭터 전환 | Tab (또는 Q) |
| 상호작용 | E (문, 스위치) |
| 일시정지 | Esc |

- 이동/점프는 조작 중인 캐릭터에게만 적용
- 전환 직후 0.1초 무적(오조작 방지)
- 키 안내는 타이틀과 튜토리얼 상단에 표시

## 8. 화면과 UI

### 8.1 해상도
- 내부 해상도 **480 × 270** (16:9), 정수배 확대 (960×540, 1440×810)
- 타일 16px, 캐릭터 16×24px 내외
- 픽셀 아트 느낌: `image-rendering: pixelated`, 안티앨리어싱 없음

### 8.2 HUD
- 좌상단: 하트(현재 캐릭터 기준), 코인 수
- 우상단: 현재 조작 캐릭터 아이콘 + 이름
- 중앙 상단: 별빛 조각 획득 수 (0/3)
- 하단: 필요 시 조작 힌트 (예: "Tab: 몽이로 전환")

### 8.3 화면 목록
1. 타이틀 (시작 / 조작법)
2. 인게임
3. 일시정지
4. 스테이지 클리어 (별빛 조각 획득 연출)
5. 게임 오버 → 체크포인트
6. 엔딩

### 8.4 아트 스타일
- **플래시 게임 감성**: 굵은 외곽선, 3~5색 팔레트, 단순한 도형, 과장된 바운스 애니메이션
- 스프라이트는 외부 이미지 없이 **Canvas 도형 + 간단한 픽셀 배열**로 그린다. (에셋 제작 부담 제거)
- 색 팔레트
  - 슈: 크림/코랄/브라운
  - 몽이: 민트/옐로우/화이트 (발광)
  - 배경: 남색/보라 계열, 별빛은 노랑
- 애니메이션: 대기 시 2프레임 흔들림, 점프 시 squash & stretch, 피격 시 0.2초 깜빡임

### 8.5 사운드
- MVP: **효과음만** (Web Audio API로 합성한 짧은 비프)
  - 점프, 코인, 피격, 전환, 퍼즐 성공, 보스 클리어
- BGM은 선택. 외부 음원 없이 간단한 루프를 합성하거나 생략한다.

## 9. 기술 설계

### 9.1 기술 스택
- **HTML5 Canvas 2D + Vanilla JavaScript (ES Modules)**
- 빌드 도구 없음. `index.html`을 브라우저로 열면 실행
- 외부 라이브러리 없음 (Phaser 불필요 — 규모가 작고, 학습/디버깅 비용 절감)
- 로컬 서버는 `python3 -m http.server 8000` 정도만 사용

> 대안: Phaser 3를 쓰면 물리/타일맵이 편하지만, 이 규모에서는 직접 구현이 더 가볍고 통제하기 쉽다. 물리 엔진은 AABB 충돌 + 중력만 직접 구현한다.

### 9.2 파일 구조 (예정)
```
testProject_4_/
├── GAME_PLAN.md          # 이 문서
├── index.html            # 엔트리
├── style.css             # 캔버스/레터박스 스타일
├── assets/               # (선택) 사운드 파일
└── src/
    ├── main.js           # 부트스트랩, 게임 루프
    ├── input.js          # 키 입력
    ├── camera.js         # 카메라 추적
    ├── physics.js        # AABB 충돌, 중력
    ├── player.js         # 슈/몽이 상태 및 능력
    ├── enemy.js          # 슬라임, 박쥐, 보스
    ├── level.js          # 타일맵 파싱, 충돌 타일
    ├── game.js           # 상태 머신(타이틀/인게임/클리어)
    ├── ui.js             # HUD, 대사 카드, 메뉴
    ├── audio.js          # 합성 효과음
    └── levels/           # 스테이지 데이터
        ├── tutorial.js
        ├── stage1.js
        └── stage2.js
```

### 9.3 핵심 시스템
- **게임 루프**: `requestAnimationFrame` + 고정 타임스텝(1/60초), 최대 3스텝 보정
- **물리**: 중력, 타일 AABB 충돌(상하좌우 분리 판정), 낙사 y > 맵 높이
- **카메라**: 조작 캐릭터 중심, 맵 경계 클램프, 전환 시 0.2초 선형 보간
- **상태 머신**: `TITLE → PLAYING → PAUSED → CLEAR → ENDING`
- **레벨**: 문자열 타일맵 + 엔티티 스폰 목록(좌표, 타입)을 분리
- **충돌 레이어**: `solid`, `hazard`, `trigger`, `oneWay` 4종

| Day 1 | 프로젝트 세팅, 게임 루프, 입력, 타일 충돌, 슈 이동/점프 | 이동 가능한 테스트 맵 |
