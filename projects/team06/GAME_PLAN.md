## 1. 한 줄 소개

B3 감방에서 시작해 **층을 하나씩 내려가며** 교도관의 시야를 피해 지상까지 탈출하는 1인칭 3D 잠행 미니게임.

---

## 2. 게임 컨셉

| 항목 | 내용 |
| --- | --- |
| 장르 | 1인칭 잠행(stealth) 아케이드 |
| 시점 | 1인칭 (도둑의 손만 화면 하단에 보임) |
| 플랫폼 | 웹 브라우저 (데스크톱, 마우스 필수) |
| 플레이 시간 | 1회 3~5분, 총 5개 층 |
| 조작 | 마우스만으로 회전 + 이동 (WASD 병행 가능) |
| 렌더링 | Canvas 2D 레이캐스팅 (순수 구현, 라이브러리 없음) |
| 핵심 재미 | "한 번만 걸리면 끝" 긴장감 + 층을 내려가는 탈출감 |

### 만들지 않을 것 (MVP 제외)
- 무기/전투, 인벤토리, 멀티플레이, 스토리 컷신, 사운드

## 3. 조작 설계

| 입력 | 동작 |
| --- | --- |
| 마우스 좌우 | 좌우 회전 (가상 조이스틱) |
| 마우스 위/아래 | 전진 / 후진 (위로 밀면 전진) |
| `W` `A` `S` `D` / 방향키 | 대안 조작 (전진·회전) |
| `R` | 현재 층 즉시 재시작 |
| `ESC` | 일시정지 (포인터 락 해제) |
| 클릭 | 시작 / 일시정지 해제 / 실패 후 재시작 |

- 마우스는 **상대 이동량(relative)** 으로만 처리한다.
  - 각 층을 시작할 때마다 카메라가 그 층의 시작 지점으로 다시 잡히므로,
    이전 층에서 커서가 어디에 있었든 자연스럽게 이어서 플레이된다.
- 가능한 환경에서는 **포인터 락**을 사용해 시스템 커서를 고정한다.
  - 락이 풀리면(ESC 등) 자동으로 일시정지된다.
- 마우스를 멈추면 가상 조이스틱이 중앙으로 복귀한다(스프링 방식).

## 4. 게임 루프

```
타이틀 → 층 로딩(B3) → 플레이
   ├─ 계단(S) 도달 → 페이드 전환 → 다음 층(B2 → B1 → 1F → 지상)
   ├─ 발각 / 감전 / 덫 → 실패 → 같은 층 재시작
   └─ ESC → 일시정지
→ 지상 탈출구(X) 도달 → 엔딩 → 타이틀
```

## 5. 층 구성 (5개 층)

| # | 층 | 목표 | 새 기믹 | 난이도 |
| --- | --- | --- | --- | --- |
| 1 | **B3 · 감방** | 계단(S) 찾기 | 교도관 1명 왕복 순찰 | ★☆☆☆☆ |
| 2 | **B2 · 복도** | 쇠창살 통과 → 계단 | **쇠창살**(주기 개폐, 통과 시 시야는 통과) + 교도관 2명 | ★★☆☆☆ |
| 3 | **B1 · 식당** | 식당 좌측 계단 | **전기충격 장치** + **덫** + 식탁(엄폐물) + 교도관 2명 | ★★★☆☆ |
| 4 | **1F · 운동장** | 운동장 계단 | 회전 **서치라이트** + 전기 장치 + 덫 4개 | ★★★★☆ |
| 5 | **지상 · 담장** | 탈출구(X) | 쇠창살 + 전기 장치 + 덫 4개 + 교도관 3명 + **60초 제한** | ★★★★★ |

- 각 층은 20×14 타일 격자(ASCII 맵)로 정의한다.
  - `#` 벽 / `.` 바닥 / `S` 계단 / `X` 탈출구
- 맵 데이터 검증: 모든 행 길이 20, 시작점→목표 BFS 도달 검증 완료.

## 6. 핵심 시스템 명세

### 6.1 플레이어 (1인칭 카메라)
- 위치(타일 좌표), 시선 각도, 충돌 반지름 0.28.
- 이동 3.1 타일/초, 회전 2.6 라디안/초.
- 원(반지름) vs 격자 셀 4점 충돌 → 축별 분리 처리.

### 6.2 교도관 AI
- 순찰: 웨이포인트 배열을 왕복, 경로 끝에서 0.5초 대기.
- 시야: 정면 ±시야각/2, 거리 7~8타일 이내, 벽에 가려지지 않아야 함.
- 시야 원뿔은 바닥에 투영된 삼각형으로 렌더(평소 노랑 / 발견 시 빨강).
- 서치라이트는 각속도로 회전하는 광원(시야각 좁고 거리 김).

### 6.3 발각 / 의심도
- 시야에 들어오면 의심도 급상승, 벗어나면 서서히 감소.
- `DETECT_RATE = 260`/sec → 약 **0.38초**면 발각(코앞이면 0.19초).
- 100 도달 시 즉시 실패 → 같은 층 재시작.

### 6.4 특수 장치
| 장치 | 데이터 | 동작 |
| --- | --- | --- |
| **쇠창살** `gates` | `cx, cy, period, duty, phase` | 주기적으로 닫힘. 닫히면 통과 불가, 시야는 통과 |
| **전기충격** `shocks` | `x, y, w, h, period, duty, phase` | 주기적으로 활성화되는 바닥. 활성 중 접촉 시 즉시 실패 |
| **덫** `traps` | `x, y` | 항상 위험한 곰덫. 반경 0.42타일 이내 접촉 시 즉시 실패 |

- 모든 주기 장치는 `clock / period + phase` 규칙(`isOn`)을 공유.
- 전기 장치는 활성화 직전 0.12주기 동안 경고 색으로 점멸.

### 6.5 계단 / 층 전환
- `S` 셀에 들어가면 1.1초 페이드 전환 → 다음 층 로드, "B3 → B2" 토스트 표시.
- 마지막 층의 `X` 셀에 들어가면 엔딩.

### 6.6 층 표시
- 계단/탈출구 셀은 바닥에 초록색으로 점멸 표시(바닥 폴리곤).

## 7. 렌더링 (레이캐스팅)

| 요소 | 방식 |
| --- | --- |
| 벽 | 스크린 컬럼 단위 DDA 레이캐스팅, 벽돌 무늬 + 거리 음영 + 면 방향 음영 |
| 바닥 | 타일별 폴리곤 투영, 체커보드 |
| 천장 | 수직 그라디언트 |
| 교도관 | 사전 렌더 스프라이트를 빌보드(z-buffer 컬럼 단위 클리핑) |
| 덫 | 바닥에 납작한 타원 + 이빨 |
| 전기 장치 / 시야 원뿔 | 바닥 폴리곤 투영 |
| 조명 | 벽 스프라이트를 화면 컬럼 단위로 클리핑하기 위한 `zbuf[]` |
| 1인칭 | 화면 우하단에 도둑의 손(장갑 + 손수건) |

- FOV 60°, 카메라 높이 0.5타일, 근접 거리 보정(Euclidean)으로 물 왜곡 제거.

## 8. 기술 설계

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 렌더링 | HTML5 Canvas 2D 레이캐스팅 | 진짜 3D 깊이감, 외부 라이브러리 0 |
| 언어 | Vanilla JavaScript (단일 파일) | 빌드 도구 불필요, 더블클릭으로 실행 |
| 입력 | Pointer Lock + 상대 마우스 이동 | 층 시작마다 커서 재초기화 |
| 에셋 | 없음 (모두 코드 드로잉) | 파일 1개로 완결 |

### 파일 구조
```
/
├─ index.html            # 3D 게임 (단일 파일, 전체 로직)
├─ legacy_topdown.html   # 이전 2D 버전 (백업)
└─ GAME_PLAN.md
```

### 주요 상수
```js
const TILE = 64;            // 1타일 = 64px
const FOV = Math.PI / 3;    // 수평 시야각 60도
const PROJ = W / 2 / Math.tan(FOV / 2);
const CAM_H = 0.5;          // 카메라 높이(타일)
const MOVE_SPEED = 3.1;     // 타일/초
const DETECT_RATE = 260;    // 의심도 상승(/sec) → 약 0.38초 발각
```
