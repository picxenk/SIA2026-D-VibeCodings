# 전쟁시대 (가제) — 미니게임 기획서

> 고전 플래시 감성의 횡스크롤 실시간 전략 디펜스 게임
> 선사시대 → 고대 → 중세 → 근대 → 미래까지 진화하며 상대 기지를 파괴한다.

---

## v3 컨셉 — 곤충 → 파충류 → 동물 → 공룡 → 외계인

> **별도의 역사 시대를 펼치지 않고, "생명의 진화" 축으로 통일했다.**
> 곤충에서 시작해 포유류·공룡을 거쳐 우주까지, 마지막은 사이버punk 톤의 외계 문명이 된다.

### 병사 실루엣 규칙 (같은 시대 안에서도 구분되도록)

| 시대 | 근접 | 원거리 | 중장갑 |
|---|---|---|---|
| 곤충 | 개미 (다리 3쌍) | 벌 (투명 날개) | 갑옷벌레 (둥근 등껍질) |
| 파충류 | 뱀 (몸통+꼬리) | 도마뱀 (뒤다리) | 악어 (긴 주둥이·이빨) |
| 동물 | 늑대 (4다리·귀) | 원숭이 (긴 팔·꼬리) | 코끼리 (코·큰 귀·굵은 다리) |
| 공룡 | 라노수어 (이족보행·턱) | 날개 공룡 (거대한 날개) | 브라키오 (긴 목·4다리) |
| 외계인 | 침입자 (큰 눈·촉수) | 드론 (로터·비행) | 메카 (각진 몸통·바이저·추진기) |

### 스킬 연출 (v3)

- 발사 순간: 화면 **흰 플래시** + **강한 진동**(shake 0.45)
- 낙하 중: 시대별 투사체(산성/독액/뼈/화염/플라즈마)가 지면까지 떨어짐
- 착지 시: **지면 충격파 링** + 폭발 파편 + 저음 폭발음
- 대상 유닛은 전량 피해, 기지는 60% 피해

- 적 유닛이 3기 이상이면 쿨다운 즉시 스페셜 스킬을 사용한다.

## 1. 프로젝트 목표

### 1.1 목표

- 플래시 게임처럼 **설명 없이 10초 안에 이해되는** 규칙
- 한 판이 **5분 안에 끝나는** 짧은 호흡
- 유닛 생산 → 전투 → 진화 → 역전의 **명확한 성장 쾌감**
- 외부 에셋 없이 **도형만으로도 완성된 느낌**이 나는 비주얼
- 모바일 대응 없이 **데스크톱 마우스/키보드**에 집중

### 1.2 성공 기준 (Definition of Done)

- [ ] 시작부터 승리/패배까지 끊김 없이 진행된다
- [ ] 5개 시대를 모두 진화할 수 있다
- [ ] 유닛 15종, 터렛 5종이 데이터로 정의되어 있다
- [ ] 적 AI가 유닛 생산·진화·터렛 건설을 스스로 한다
- [ ] 5분 내외의 경기가 60fps로 돌아간다
- [ ] 콘솔 에러 0건, 링크 하나로 배포 가능하다

### 1.3 이번에 하지 않는 것 (Non-goals)

- 멀티플레이, 계정, 서버 저장
- 모바일 터치 UI
- 다중 레인, 지형, 시야 시스템
- 스토리 컷신, 대사
- 유닛 개별 조작(선택/이동 명령)
- 사운드/음악 외부 파일 구매

## 2. 레퍼런스 분석 — 전쟁시대(Age of War)

### 2.1 레퍼런스의 핵심 구조

1. 좌우 기지 + 중앙 전선
2. 자동으로 차오르는 골드로 유닛 생산
3. 유닛은 알아서 전진하고, 적을 만나면 싸움
4. 골드를 모아 **시대를 진화**하면 새 유닛/터렛 해금
5. 기지를 부수면 승리

### 2.2 우리가 가져갈 것

- 좌우 1:1 대칭 전선
- 자동 골드 수급 + 처치 보너스
- 시대 진화에 따른 유닛/터렛 해금
- 유닛 자동 전투 (컨트롤 최소화)

### 2.3 우리가 단순화할 것

| 레퍼런스 | 이 프로젝트 |
|---|---|
| 시대별 다양한 유닛 다수 | 시대별 3종 (근접/원거리/중장갑) |
| 터렛 여러 종류·슬롯 | 터렛 슬롯 2개, 시대별 1종 |
| 특수 공격(운석 등) | P1 확장으로 보류 |
| 화려한 스프라이트/애니메이션 | 도형 + 이모지 + 간단한 이펙트 |
| 긴 캠페인 | 단판 승부 + 난이도 3단계 |

## 3. 핵심 재미 (Fun Pillars)

1. **성장의 쾌감** — 시대가 바뀌는 순간 배경, 유닛, 사운드가 전부 바뀐다.
2. **숫자의 압박** — 유닛을 계속 뽑을지, 참고 진화할지 매 순간 선택한다.
3. **역전의 순간** — 터렛 2기로 버티다 진화 한 번으로 전선을 밀어내는 그림.
4. **짧은 한 판** — 3~6분, "한 판만 더"가 자연스럽다.

### 재미 검증 질문

- 진화를 안 하고 유닛만 뽑는 전략이 더 강한가? → **아니어야 한다.**
- 최신 시대 유닛만 뽑는 게 항상 정답인가? → **비용 효율로 아니어야 한다.**
- 뒤처진 쪽이 무기력한가? → **기지 앞 방어 이점 + 소폭 수급 보정으로 아니어야 한다.**

## 4. 게임 규칙

### 4.1 승리 / 패배

- **승리**: 적 기지 HP를 0으로 만든다.
- **패배**: 내 기지 HP가 0이 된다.
- 시간 제한 없음. 무승부 방지를 위해 10분 경과 시 기지 HP 비율로 판정.

### 4.2 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│ [골드 320] [시대: 선사]   ⏱ 02:14   [적 기지 HP ████████░░] │  ← 상단 HUD
│                                                              │
│   ███                                                        │
│   ███                 🗿      🏹                             │
│   ███        🪓              ⚔️          🏰                  │  ← 전장 (지면 y=440)
│  내 기지                     유닛들                적 기지    │
│                                                              │
│ [1 곤봉병 50] [2 투석병 70] [3 공룡 160]   [터렛 180] [진화]  │  ← 하단 명령 바
└──────────────────────────────────────────────────────────────┘
```

- 캔버스 논리 좌표: 960 × 540
- 지면: y = 440
- 내 기지 x = 80, 적 기지 x = 880
- 내 유닛 스폰 x = 140, 적 유닛 스폰 x = 820
- 터렛 슬롯: 내 진영 x = 210 / 260, 적 진영 x = 750 / 700
- 상단 HUD 70px, 하단 명령 바 90px는 캔버스 위에 오버레이

### 4.3 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 유닛 생산, 터렛 건설, 진화 |
| 1 / 2 / 3 | 유닛 생산 |
| Q | 터렛 건설 |
| E | 시대 진화 |
| Space | 일시정지 |
| R | 재시작 (게임 종료 후) |

### 4.4 핵심 루프

```
골드 자동 수급
   ↓
유닛 생산 (골드 소모 + 생산 쿨다운)
   ↓
유닛이 자동으로 전진 → 적 유닛/터렛/기지와 전투
   ↓
적 처치 시 보너스 골드
   ↓
골드를 모아 시대 진화 → 새 유닛/터렛 해금
   ↓
전선을 밀어 적 기지 파괴 → 승리
```

### 4.5 자원 — 골드

| 항목 | 규칙 |
|---|---|
| 시작 골드 | 300 |
| 자동 수급 | 시대별 초당 10 / 14 / 20 / 28 / 38 |
| 처치 보너스 | 처치한 유닛 생산비의 20% |
| 최대 보유 | 9,999 (표시 상한) |
| 소비처 | 유닛 생산, 터렛 건설/철거, 시대 진화 |

- 골드는 **실시간으로 차오른다.** 숫자가 오르는 것을 눈에 보이게 한다.
- 적 기지 타격 시 소량의 골드 보너스(타격당 1)를 주어 공격적인 플레이를 보상한다.

### 4.6 유닛 생산

- 유닛별 **생산 쿨다운**이 있다 (근접 1.0s / 원거리 1.2s / 중장갑 2.5~3.0s).
- 골드가 부족하거나 쿨다운 중이거나 **유닛 상한(12기)** 이면 생산 불가.
- 생산 버튼에 쿨다운 게이지와 가격을 표시한다.
- 유닛은 스폰 즉시 전진하며, 플레이어가 개별 조작할 수 없다.

### 4.7 시대 진화

| 진화 | 비용 | 진화 시간 | 해금 |
|---|---|---|---|
| 선사 → 고대 | 400 | 1.5s | 고대 유닛 3종, 화살탑 |
| 고대 → 중세 | 1,000 | 1.5s | 중세 유닛 3종, 대포탑 |
| 중세 → 근대 | 2,200 | 2.0s | 근대 유닛 3종, 기관포탑 |
| 근대 → 미래 | 4,000 | 2.0s | 미래 유닛 3종, 플라즈마탑 |

- 진화 중에는 유닛 생산 불가 (진화 진행 바 표시).
- 진화 완료 시 **배경 테마, 유닛 외형, 사운드**가 즉시 바뀐다.
- 진화해도 이전 시대 유닛은 계속 생산 가능하다 (가성비 선택지).
- 진화 직후 3초간 기지에 작은 방어 버프(받는 피해 -20%)를 주어 진화 타이밍의 리스크를 완화한다.

### 4.8 터렛

- 슬롯은 진영당 **2개**, 고정 위치.
- 현재 시대의 터렛 1종만 건설 가능.
- 건설 즉시 완성, 철거 시 건설비의 50% 환급.
- 터렛은 사거리 내 적 유닛을 자동 공격한다.
- 터렛도 공격 대상이며 HP가 0이면 파괴된다.

### 4.9 전투 규칙

**유닛 상태**: `advance` → `attack` → `dead`

**타겟 우선순위**

1. 사거리 내 가장 가까운 적 유닛
2. 사거리 내 적 터렛
3. 사거리 내 적 기지
4. 사거리 내 대상이 없으면 전진

**공격 방식**

- 근접: 즉시 데미지, 짧은 사거리(25~40)
- 원거리: 투사체 생성 → 목표 도달 시 데미지 (시각적 피드백)
- 중장갑: 느린 공격 속도, 높은 HP/데미지

**기타**

- 유닛끼리 물리 충돌 없음. 같은 x에 겹칠 수 있으나 ±10px 랜덤 오프셋으로 겹침을 완화.
- 넉백 없음. 피격 시 0.1초 색 플래시만.
- 사망 시 0.3초 페이드 후 제거, 처치 보너스 지급.
- 기지는 이동/공격하지 않는다.

### 5.4 적 AI

AI는 0.5초마다 아래 우선순위로 의사결정한다.

```
1. 진화 가능 && (골드 >= 진화비 + 200) && (내 유닛 수 < 4) → 진화
2. 터렛 슬롯 여유 && 골드 >= 터렛비 + 150 && 적 유닛이 내 진영에 2기 이상 → 터렛 건설
3. 유닛 상한 미만 && 골드 >= 최저가 유닛 → 유닛 생산
4. 그 외 → 대기 (골드 축적)
```

- 유닛 선택 가중치: 최신 시대 60%, 이전 시대 40% (가성비 섞기)
- 역할 선택 가중치: 근접 45%, 원거리 35%, 중장갑 20%
- 같은 유닛 연속 생산 시 약간의 랜덤 지연(0~0.6s)을 두어 기계적인 느낌을 줄인다.
- **루프 방지**: 3초 이상 아무 행동도 못 하면 가장 싼 유닛을 강제 생산 시도.

### 5.5 난이도

| 난이도 | AI 골드 배율 | 의사결정 주기 | 진화 여유 골드 | 시작 골드 |
|---|---:|---:|---:|---:|
| 쉬움 | 0.8× | 1.0s | +400 | 250 |
| 보통 | 1.0× | 0.5s | +200 | 300 |
| 어려움 | 1.3× | 0.35s | +100 | 350 |

- 플레이어 수급은 난이도와 무관하게 동일하다.
- 어려움은 "AI가 더 자주, 더 과감하게" 행동하는 방식으로 압박한다.

## 6. UX / UI

### 6.1 상단 HUD

- 좌측: 골드(아이콘 + 숫자, 증가 시 살짝 튀는 애니메이션)
- 중앙: 현재 시대 이름 + 경과 시간
- 우측: 적 기지 HP 바 (색: 빨강), 내 기지 HP는 화면 좌하단 기지 위에 표시
- 진화 진행 중이면 중앙에 진행 바

### 6.2 하단 명령 바

- 유닛 버튼 3개: 아이콘(이모지), 이름, 가격, 단축키, 쿨다운 오버레이
- 골드 부족 시 버튼 회색 처리
- 터렛 버튼: 가격 + 남은 슬롯 표시
- 진화 버튼: 가격 + "다음 시대: 고대" 미리보기
- 버튼은 캔버스가 아니라 **HTML DOM**으로 만들어 접근성과 클릭 처리를 단순화한다.

### 6.3 피드백

| 상황 | 피드백 |
|---|---|
| 유닛 생산 | 스폰 지점 먼지 이펙트 + 짧은 사운드 |
| 피격 | 0.1s 흰색 플래시, 데미지 숫자(선택) |
| 유닛 사망 | 0.3s 페이드 + 작은 파편 |
| 진화 | 화면 플래시 + 배경 전환 + 상승음 |
| 기지 피격 | 화면 흔들림(2px, 0.15s) |
| 승리/패배 | 오버레이 + 결과(시간, 처치 수, 진화 단계) + 재시작 버튼 |

### 6.4 접근성 / 편의

- 모든 버튼에 단축키 병기
- 색맹 대비: 아군 파랑 / 적군 빨강 + 외형(깃발)으로도 구분

### 7.4 게임 루프

```js
// 고정 타임스텝 + 렌더 보간 없이 단순하게
const STEP = 1 / 60;
let acc = 0, last = performance.now();

function frame(now) {
  let dt = Math.min((now - last) / 1000, 0.1); // 탭 복귀 시 폭주 방지
  last = now;
  acc += dt;

  while (acc >= STEP) {
    update(STEP);
    acc -= STEP;
  }
  render();
  requestAnimationFrame(frame);
}
```

- `update`는 순수 로직, `render`는 상태를 읽기만 한다.
- 일시정지 시 `update` 호출을 건너뛴다.
- 유닛 12 + 적 12 + 투사체 수십 개 수준이라 성능 문제는 사실상 없다.

### 7.5 핵심 로직 의사 코드

**유닛 갱신**

```js
function updateUnit(u, dt, world) {
  const target = findTarget(u, world); // 우선순위 규칙

  if (!target) {
    u.x += u.dir * u.speed * dt;       // 전진
    return;
  }

  if (distance(u, target) <= u.range + target.radius) {
    u.cooldown -= dt;
    if (u.cooldown <= 0) {
      attack(u, target, world);         // 근접 즉시 / 원거리 투사체
      u.cooldown = u.attackInterval;
    }
  } else {
    u.x += u.dir * u.speed * dt;       // 사거리까지 접근
  }
}
```

### 7.6 렌더링

- 배경: 시대별 하늘 그라데이션 + 원경 실루엣 2~3겹(패럴랙스 없이 정적이어도 무방).
- 지면: 어두운 띠 + 시대별 텍스처 느낌의 점/선.
- 유닛: 몸통(둥근 사각형) + 역할별 이모지 + 진영 색 테두리 + HP 바.
  - 예: 🪓 곤봉병, 🏹 투석병, 🦖 공룡, 🛡️ 기사, 🔫 소총병, 🤖 메카
- 기지: 시대별로 성/건물 실루엣을 도형으로 구성, HP 바를 위에 표시.
- 이펙트: 원/선/파편 파티클, 화면 흔들림.
- 텍스트: 시스템 폰트 사용 (외부 폰트 로드 없음).
- `devicePixelRatio`를 반영해 선명하게 그린다.

| 탭 복귀 시 시간 폭주 | 버그 | dt 상한 0.1s, 비활성 시 자동 일시정지 |

## 11. 밸런스 조정 가이드

### 판단 지표

- **비용당 DPS** = `공격력 / 공격주기 / 비용`
- **비용당 유효 HP** = `HP / 비용`
- 같은 시대 안에서 역할별로 한 지표가 과도하게 앞서지 않게 한다.
- 시대가 바뀔 때 DPS는 대략 **1.5~1.8배** 상승하도록 유지한다.

### 자주 하는 조정

| 증상 | 조정 |
|---|---|
| 초반 러시가 너무 강함 | 기지 HP ↑, 진화 비용 ↓, 초반 수급 ↓ |
| 게임이 너무 김 | 기지 HP ↓, 유닛 공격력 ↑ |
| 진화가 무의미함 | 신시대 유닛 비용 효율 ↑, 진화 비용 ↓ |
| 진화만 하는 게 정답 | 진화 중 생산 불가 시간 ↑, 진화 비용 ↑ |
| 터렛이 사기 | 터렛 HP ↓, 건설비 ↑, 슬롯 1개로 축소 |

### 테스트 방법

1. 같은 난이도로 5판 연속 플레이하며 승패/소요 시간 기록
2. 각 시대 진화 시점(초)과 최종 승리 시간을 메모
3. "이번 판에서 가장 재미있었던 순간"을 한 줄 기록
4. 수치는 한 번에 하나만 바꾼다
