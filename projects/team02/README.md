# 전쟁시대 (War Ages) — 미니게임 MVP

고전 플래시 게임 『전쟁시대(Age of War)』 감성의 횡스크롤 실시간 전략 디펜스 게임입니다.

**곤충 → 파충류 → 동물 → 공룡 → 외계인** — 생명이 진화하는 5개 단계를 거치며 적 기지를 파괴하세요.

## 실행 방법

빌드나 설치가 필요 없습니다. 두 가지 중 편한 방법을 쓰세요.

1. **그냥 열기**: `index.html`을 더블클릭 (브라우저에서 바로 실행)
2. **로컬 서버** (선택):
   ```bash
   ruby -run -e httpd . -p 8766
   # http://localhost:8766 접속
   ```

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 / `1` `2` `3` | 유닛 생산 |
| `Q` | 터렛 건설 |
| `S` | 스페셜 스킬 (광역 데미지) |
| `E` | 시대 진화 |
| `Space` | 일시정지 |
| `R` | 게임 오버 후 다시 시작 |
| 🔊 버튼 | 소리 켜기/끄기 |

## 규칙 한 줄 요약

- 골드는 자동으로 차오른다 → 유닛을 뽑아 전선을 민다
- 적 처치 시 보너스 골드 → 모으면 **시대 진화**
  (곤충 → 파충류 → 동물 → 공룡 → 외계인)
- 진화하면 새 유닛 3종 + 더 강한 터렛 해금
- `S` 키로 광역 스킬(무벌레 대군 → 궤도 빔) 사용
- 적 기지 HP를 0으로 만들면 승리

## 파일 구조

```
index.html   # 화면 뼈대
style.css    # HUD/버튼/오버레이 스타일
data.js      # 시대/유닛/터렛/난이도 수치 (밸런스 조정은 여기서)
game.js      # 게임 로직, 적 AI, 렌더링
ui.js        # HUD 갱신, 버튼, 입력, 게임 루프
```

밸런스를 바꾸려면 `data.js`의 숫자만 수정하면 됩니다.
