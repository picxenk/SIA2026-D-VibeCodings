# 몬스터 배틀 아레나 (MVP)

간단한 2D 턴제 몬스터 배틀 미니게임입니다. 6종의 오리지널 몬스터를 모으고,
타입 상성을 활용해 6개 스테이지를 차례로 클리어하는 것이 목표입니다.

- 순수 HTML5 Canvas + 바닐라 JavaScript (외부 라이브러리·에셋·빌드 도구 없음)
- 몬스터 그래픽과 배경은 모두 코드로 그린 절차적 아트
- BGM과 효과음은 WebAudio로 합성
- 저장은 `localStorage` (실패 시 메모리 저장으로 자동 대체)

## 실행 방법

ES 모듈이 아닌 일반 스크립트이므로 `index.html`을 브라우저로 열어도 동작합니다.
다만 일부 브라우저는 `file://`에서 저장소/오디오를 제한할 수 있어 로컬 서버 실행을 권장합니다.

```bash
# 프로젝트 폴더에서 (Ruby 예시)
ruby -run -e httpd . -p 8124

# 또는 Python이 정상 동작하는 환경이라면
python3 -m http.server 8124
```

그다음 <http://localhost:8124/index.html> 을 엽니다.

> macOS 기본 Ruby의 WEBrick은 한글 경로에서 500 오류를 낼 수 있습니다.
> 이 경우 폴더를 ASCII 경로로 복사한 뒤 서버를 실행하세요.

## 게임 흐름

1. **타이틀** — 새 게임 또는 이어하기
2. **스타터 선택** — 엠버펍(불) / 아쿠아블(물) / 스프라우틀(풀) 중 1종
3. **아레나 로드맵** — 스테이지 선택, 출전 몬스터 변경, 진행도 확인
4. **배틀** — 1대1 턴제. 속도가 높은 쪽이 먼저 행동
5. **결과** — 획득 EXP, 레벨 업, 새 몬스터 해금, 재도전/다음 스테이지

### 성장 규칙

- 플레이어 레벨은 모든 보유 몬스터에 공유됩니다.
- 첫 클리어 시 해당 스테이지의 온전한 EXP를, 재도전(연습)에서는 30%를 획득합니다.
- 새 몬스터는 특정 스테이지를 처음 클리어할 때 해금됩니다.

### 타입 상성

| 공격 ↓ / 방어 → | 불 | 물 | 풀 | 노말 |
| --- | --- | --- | --- | --- |
| 불 | 0.5× | 0.5× | 2× | 1× |
| 물 | 2× | 0.5× | 0.5× | 1× |
| 풀 | 0.5× | 2× | 0.5× | 1× |
| 노말 | 1× | 1× | 1× | 1× |

## 콘텐츠

- **몬스터 6종**: 엠버펍, 아쿠아블, 스프라우틀, 페블릿, 볼트위습, 리플링
- **기술 12개**: 타입별 공격 기술 + 노말 기술, 위력/명중률 차등
- **스테이지 6개**: 초원 입구 → 불씨 언덕 → 잔잔한 개울 → 수풀 미로 → 번개 마당 → 아레나 결승

## 테스트

<http://localhost:8124/tests.html> 을 열면 엔진 테스트가 바로 실행됩니다.

검증 항목: 상성 배율, 몬스터 생성/레벨 제한, 대미지·급소·최소 피해,
명중 판정 경계, EXP/레벨업/최고 레벨, 턴 순서, AI 선택, 데이터 무결성, 난이도 곡선.

## 기획서와의 차이 (의도된 단순화)

`GAME_PLAN.md`는 Phaser + Vite + TypeScript 구성을 가정했지만, 이 환경에는
Node/npm이 없어 **의존성 없는 Canvas 2D 구현**으로 대체했습니다. 그 밖의 차이:

- **공유 레벨**: 몬스터별 개별 EXP 대신 플레이어 공통 레벨 1개로 단순화
- **대미지 계수**: 계획서의 50 대신 15를 사용해 한 판을 3~6턴으로 압축
- **해금 방식**: 스테이지 첫 클리어 시 즉시 해금 (별도 상점/포획 없음)
- **연습 배틀**: 재도전 EXP 30% 지급으로 반복 파밍 완화
- **저장**: 계획서의 슬롯 저장 대신 단일 슬롯 자동 저장
- **전투 파티**: 1대1 고정 (교체·아이템·상태이상 없음)
- **개발 위치**: `monster-arena/` 하위 폴더 대신 저장소 루트에 배치

## 크레딧

- 기획·코드·아트·사운드: 이 프로젝트에서 새로 제작한 오리지널 콘텐츠
- 폰트: 사용자 시스템 폰트 (Apple SD Gothic Neo / Malgun Gothic / Noto Sans KR / sans-serif)
- 외부 이미지·사운드·폰트 파일을 사용하지 않았습니다.

몬스터 이름과 디자인은 특정 상용 프랜차이즈를 참조하지 않은 오리지널 창작물입니다.

## 알려진 제한

- 단일 저장 슬롯이며 세이브 백업/내보내기는 없습니다.
- 브라우저가 `localStorage`를 막으면 새로고침 시 진행도가 사라집니다.
- 키보드 포커스가 페이지에 있을 때만 키 조작이 동작합니다.
- 모바일 세로 화면에서는 가로 회전 안내가 표시됩니다 (플레이는 가능).
