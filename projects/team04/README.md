# 슈와 몽이: 별빛 수호대 (MVP)

별빛을 잃은 마을을 구하는, 아주 작은 2인 동시 조작 협동 RPG 미니게임입니다.
두 명이 각자 키보드를 나눠 슈와 몽이를 동시에 조작합니다. (한 명이 둘 다 조작해도 됩니다)

## 실행 방법

`index.html`을 브라우저에서 열면 바로 실행됩니다. (별도 설치·빌드 없음)

로컬 서버로 열고 싶다면:

```bash
ruby -run -e httpd . -p 8000
# 브라우저에서 http://localhost:8000 접속
```

## 조작 (2인 동시)

| 캐릭터 | 이동 | 점프 | 공격 |
|---|---|---|---|
| **슈** (왼쪽화살표 키) | ← → | ↑ | **오른쪽 Shift** |
| **몽이** (WASD) | A / D | W (2단 점프·활공) | **왼쪽 Shift** |

- **슈**: 상자 밀기, 근접 공격, 체력 5
- **몽이**: 폭 1칸 틈 통과, 2단 점프·활공, 어둠 밝히기, 체력 3
- **밟기**: 공중에서 적 위로 떨어지면 마리오처럼 밟아서 처치!
- 일시정지 `Esc`, 재시작은 일시정지 중 `R`

## 아이템

상자(나무 상자)를 공격해서 부수면 아이템이 드롭됩니다.

| 아이템 | 효과 |
|---|---|
| ⭐ 별 아이템 | 해당 캐릭터의 공격이 **원거리 투사체**로 파워업 |
| ❤ 하트 | 체력 +2 회복 |

⚠️ 밀어서 쓰는 퍼즐 상자는 부술 수 없습니다.

## 스테이지

1. **별빛 숲 입구** — 몽이만 지나갈 수 있는 틈과 스위치
2. **흔들다리 협곡** — 상자를 밀어 올라가 무거운 레버 당기기
3. **그림자 동굴** — 몽이의 빛으로 어둠을 밝히고 높은 스위치 누르기
4. **별등 광장** — 그림자 정령 보스전

별빛 조각 3개를 모으면 엔딩입니다. 총 플레이 타임은 약 10~15분입니다.

## 파일 구조

```
index.html          엔트리
style.css           화면 스타일
src/levels.js       스테이지 타일맵 데이터
src/input.js        키 입력
src/audio.js        Web Audio 효과음
src/game.js         게임 로직 / 렌더링
src/main.js         게임 루프
GAME_PLAN.md        기획서
```

## 참고

- 원작 《슈 게임》 시리즈의 팬 게임을 염두에 둔 **비상업 프로토타입**입니다.
- 외부 이미지·음원 없이 Canvas 도형과 합성 효과음만 사용합니다.
- 공개 배포 시에는 원작자 허락을 확인하거나 오리지널 캐릭터로 교체하세요.
