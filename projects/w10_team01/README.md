# 🍕 Pizza Rush — 피자 만들기 미니 게임 (v2)

`PIZZA_GAME_PLAN.md`의 MVP를 확장한 버전입니다.
빌드 도구나 설치 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

1. `index.html`을 브라우저로 연다 (더블클릭).
2. 난이도를 고르고 `시작하기`를 누른다.

별도 서버는 필요 없습니다.

## 플레이 방법

1. 오른쪽 **손님 대기열**에서 맨 앞 손님의 주문을 확인한다.
2. 아래 재료 버튼으로 **도우 → 소스 → 치즈 → 토핑** 순서로 올린다.
3. `오븐에 넣기` → 게이지가 **초록 구간**일 때 `꺼내기`.
4. 조각 수(4·6·8)를 고르고 `서빙하기`.
5. 결과 확인 후 **자동으로 다음 손님이 들어온다** ( `다음 손님` 버튼으로 즉시 넘길 수도 있음).

### 재료

| 분류 | 종류 |
|---|---|
| 도우 | 기본 도우, 씬 도우, 치즈 크러스트 |
| 소스 | 토마토, 화이트, 바질 페스토 |
| 치즈 | 모차렐라, 체다, 고르곤졸라 |
| 토핑 | 페퍼로니, 버섯, 올리브, 파인애플, 양파, 피망, 베이컨, 새우 |

### 점수

```
기본 점수 = 정확도 × 굽기 배율 × 조각 배율 × 난이도 배율
토핑 보너스 = 올린 토핑 가치의 합 (최대 12개)
최종 점수 = (기본 점수 + 토핑 보너스) × 콤보 배율 + 팁
```

- **토핑을 많이 올릴수록 토핑 보너스가 커진다.** (새우·베이컨이 고득점)
- 단, 주문에 없는 토핑은 정확도를 떨어뜨린다.
- 콤보는 정확도 80% 이상일 때 쌓인다.
- 시간 초과 또는 정확도 50% 미만/탄 피자는 목숨 -1.

### 난이도

| 난이도 | 손님 인내심 | 요구 토핑 수 | 점수 배율 |
|---|---|---|---|
| 쉬움 | 60초 | 1~2개 | x1.0 |
| 보통 | 42초 | 2~3개 | x1.1 |
| 어려움 | 30초 | 3~4개 | x1.25 |

- 대기 중인 손님의 인내심은 앞 손님보다 절반 속도로 줄어든다.
- 스테이지가 오를수록 인내심이 조금씩 짧아진다.

### 소리

- Web Audio API로 만든 배경 음악과 효과음(재료 선택, 치즈 뿌리기, 토핑 올리기, 오븐, 서빙, 손님 등장/이탈 등)이 재생됩니다.
- 우측 상단 `소리 ON/OFF` 버튼으로 끌 수 있고, 설정은 브라우저에 저장됩니다.
