# 🎣 별빛 낚시 (Starlight Fishing) v0.2

Stardew Valley의 낚시 미니게임에서 영감을 받은 **초간단 2D 웹 낚시 게임**입니다.
호숫가에 앉아 찌를 던지고, 초록 바를 움직여 물고기를 잡고, 상점에 팔아 낚싯대를 업그레이드하세요.
도감 12종을 채우는 것이 최종 목표입니다.

- 기획서: [`PLAN.md`](./PLAN.md)
- 기술: **바닐라 JS + Canvas 2D** (빌드 없음, 의존성 0)
- 해상도: 480 × 270 (픽셀 아트, 정수 배율 확대)
- 프레임: 고정 60Hz 업데이트

| 동작 | 데스크톱 | 모바일 |
|---|---|---|
| 시작 / 던지기 | 클릭, Space, Enter | 탭 |

| 초록 바 하강 | 버튼 떼기 | 손 떼기 |

미니게임에서 초록 바가 물고기와 겹치면 진행 게이지가 차오르고, 벗어나면 줄어듭니다.
100%가 되면 포획, 0%가 되면 놓칩니다.

## 💰 판매 가격 · 낚싯대 밸런스

### 물고기 기본가

| 물고기 | 기본가 | 물고기 | 기본가 |
|---|---:|---|---:|
| 피라미 | 18 G | 은빛송어 | 120 G |
| 붕어 | 26 G | 무지개송어 | 130 G |
| 송사리 | 32 G | 장어 | 240 G |
| 잉어 | 60 G | 달빛잉어 | 260 G |
| 메기 | 110 G | 황금붕어 | 600 G |
| | | 유령메기 | 650 G |
| | | 전설의 별고기 | 1,200 G |

실제 판매가는 **기본가 × 크기 보정(0.75 ~ 1.25배)** 입니다.
같은 물고기라도 클수록 비싸게 팔립니다. (`js/fish.js`의 `fishPrice`)

### 낚싯대

| 낚싯대 | 가격 | 초록 바 | 희귀(★3+) | 입질 반응 | 큰 물고기 |
|---|---:|---:|---:|---:|---:|
| 나무 낚싯대 | 기본 | — | — | — | — |
| 강화 낚싯대 | 300 G | +15% | +20% | +10% | +3% |
| 은빛 낚싯대 | 1,200 G | +30% | +45% | +20% | +6% |
| 황금 낚싯대 | 3,200 G | +45% | +80% | +30% | +10% |

- 희귀 보정은 ★3 이상 물고기의 출현 가중치에 적용됩니다.
- 밤 시간대 기준 ★3+ 출현율: 나무 **22.4%** → 황금 **33.6%** (30,000회 몬테카를로).
- 큰 물고기 보정은 크기 난수 지수를 낮춰 상위 크기가 나올 확률을 높입니다.
- 낚싯대 데이터는 `js/rods.js`에서 한눈에 수정할 수 있습니다.

## 🐟 물고기와 시간대

| 시간대 | 플레이 횟수 | 등장 물고기 |
|---|---|---|
| 낮 | 0–4, 15–19, … | 피라미, 붕어, 송사리, 잉어, 무지개송어 |
| 노을 | 5–9 | 피라미, 붕어, 송사리, 은빛송어, 황금붕어 |
| 밤 | 10–14 | 피라미, 붕어, 송사리, 메기, 장어, 달빛잉어, 유령메기, 별고기 |

시간대는 `totalCasts % 15`로 결정됩니다. 5회마다 바뀌므로 한 세션에서 모든 시간대를 볼 수 있습니다.
각 물고기의 출현 확률은 `js/fish.js`의 `weight`로 조정합니다.

## 🔧 밸런스 튜닝

### 낚시 손맛 — `js/config.js`의 `FISHING`

| 파라미터 | 기본값 | 의미 |
|---|---|---|
| `POWER_SPEED` | 1.25 | 캐스팅 게이지 왕복 속도 |
| `BITE_WINDOW` | 0.62 | 입질 반응 시간(초), 낚싯대 배율 적용 |
| `GAIN` / `LOSS` | 22 / 18 | 게이지 증가/감소 (초당) |
| `START_PROGRESS` | 18 | 미니게임 시작 게이지 |
| `TIME_LIMIT` | 45 | 미니게임 제한 시간(초) |
| `GRAVITY` / `LIFT_ACCEL` | 900 / 1600 | 바 낙하/상승 가속 |
| `MAX_VY` | 260 | 바 최대 속도 |

물고기 난이도는 `js/fish.js`의 `difficulty`(1~5)로 조정합니다.
난이도가 높을수록 **초록 바가 작아지고**, 물고기가 **더 빠르고 크게** 움직입니다.

### 경제 — `js/fish.js` · `js/rods.js`

- 물고기 가격: `BASE_PRICE`
- 크기 보정 폭: `fishPrice()`의 `0.75 + 0.5 * t`
- 낚싯대 가격/성능: `RODS` 배열의 `price` · `bar` · `rare` · `bite` · `size`

## 🧹 저장 데이터 초기화

개발자 도구 콘솔에서:

```js
localStorage.removeItem("starlight-fishing-v1");
location.reload();
```

저장 스키마는 v2(`gold` / `inventory` / `ownedRods` / `rod`)이며,
v1 데이터가 있으면 자동으로 마이그레이션됩니다.
