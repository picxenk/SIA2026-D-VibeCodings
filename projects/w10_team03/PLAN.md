# 🎣 별빛 낚시 — 기획서 (v0.2)

> Stardew Valley의 낚시 미니게임에서 영감을 받은, 플래시 게임 수준의 초간단 2D 낚시 게임.
> 아기자기한 픽셀 아트 · 5분 안에 한 사이클을 즐길 수 있는 웹 게임.

---

## 1. 한 줄 소개

호숫가에 앉아 낚싯대를 던지고, 초록 바를 움직여 물고기를 잡아 도감을 채우는 **원버튼 낚시 게임**.

- **플랫폼**: 웹 브라우저 (데스크톱 + 모바일 터치)
- **장르**: 캐주얼 낚시 / 수집
- **플레이 타임**: 1회 3~10분, 도감 완성 30분~1시간
- **해상도**: 480 × 270 (16:9), 정수 배율 확대 (×2 ~ ×4)
- **목표 프레임**: 60 FPS
- **개발 기간(목표)**: 2주 (1인 기준, 하루 3~4시간)

### 결정 사항 (가정)

| 항목 | 결정 | 이유 |
|---|---|---|
| 기술 스택 | **빌드 없는 바닐라 JS + Canvas 2D** (클래식 스크립트) | 개발 환경에 Node가 없어 Vite/TS 대신 선택. 파일 더블클릭만으로 실행되고, 정적 호스팅에 그대로 배포 가능 |
| 렌더링 | 픽셀 아트, `image-rendering: pixelated` | 아기자기한 감성 + 구현 단순 |
| 입력 | 마우스 클릭 유지 / Space / 터치 | "누르고 있기" 하나로 조작 통일 |
| 저장 | `localStorage` (도감, 최고 기록) | 서버 불필요 |
| 언어 | 한국어 우선 (영문은 여유 시) | — |
| 사운드 | WebAudio 직접 재생 (짧은 효과음 위주) | 외부 라이브러리 최소화 |

## 2. 목표와 범위

### 2.1 이 게임이 주는 것

1. **던지고 → 기다리고 → 당기는** 낚시의 손맛을 30초 안에 이해시킨다.
2. 물고기를 잡을 때마다 **"이번엔 뭐가 나올까"** 하는 기대감.
3. 도감을 채우는 **수집의 만족감**.
4. Stardew Valley를 떠올리게 하는 **따뜻한 색감과 잔잔한 분위기**.

### 2.2 MVP에 포함 (In Scope)

- 타이틀 화면 → 호숫가 낚시 화면 → 결과 화면 → 도감
- 낚시 4단계: **캐스팅 → 입질 대기 → 입질 → 미니게임**
- Stardew식 **초록 바(그린 바) 미니게임**
- 물고기 **12종** + 희귀도 + 크기 기록
- 도감 (잡은 물고기 실루엣 공개)
- 시간대(낮/노을/밤) 3종 배경 변화
- 효과음 6종 + 잔잔한 BGM 1곡(또는 무음 옵션)
- 모바일 터치 대응, 세로 화면 대응

### 2.3 MVP에서 제외 (Out of Scope)

- 캐릭터 이동 / 맵 탐험 / 상점 / 판매 / 인벤토리
- 멀티플레이, 서버 랭킹
- 계절 시스템, 날씨(비/눈) 연출
- 스토리, NPC 대화
- 물고기 도감 외의 성장/스킬 트리
- Steam/모바일 앱 패키징

> ⚠️ **저작권 주의**: Stardew Valley의 이미지·캐릭터·이름·음악을 절대 사용하지 않는다.
> "분위기와 색감의 오마주"까지만. 모든 아트는 직접 제작하거나 라이선스가 명확한 에셋을 사용한다.

## 3. 핵심 재미 구조

### 3.1 코어 루프

```
   ┌─────────────────────────────────────────────┐
   │                                             │
   ▼                                             │
 [던진다] → [기다린다] → [입질!] → [미니게임] → [결과]
   │          (긴장)      (반사)     (집중)      │
   │                                             │
   ├────────── 도감 / 최고 기록 갱신 ◀───────────┤
   │                                             │
   └── [상점] 판매 → 골드 → 낚싯대 업그레이드 ◀──┘
```

- **긴장**: 입질까지의 짧은 대기 (1.5~5초). 물결과 찌의 미세한 움직임으로 "곧 온다"를 암시.
- **반사**: 입질 순간 0.6초 안에 클릭. 놓치면 물고기가 도망.
- **집중**: 초록 바를 물고기 위에 유지. 미니게임의 핵심 손맛.
- **보상**: 크기 기록, 희귀 물고기, 도감 완성도.

### 3.2 손맛의 3요소

| 요소 | 구현 |
|---|---|
| 즉각 반응 | 입력 → 1프레임(16ms) 내 바 이동 시작 |
| 과하지 않은 관성 | 중력 + 가속도로 "묵직하게 떠오르는" 느낌 |
| 명확한 피드백 | 물고기 잡힘 순간 화면 플래시 + 효과음 + 파티클 |

## 4. 게임플레이 설계

### 4.1 화면 흐름

```
[타이틀]
   │ 클릭 / Space
   ▼
[낚시 화면] ──(ESC)──> [일시정지] ──> [타이틀]
   │
   │ 1) 캐스팅: 파워 게이지 (좌우로 오가는 바) → 클릭으로 거리 결정
   │ 2) 대기: 찌가 물 위에 떠 있음 (1.5~5초)
   │ 3) 입질: 찌가 "풍덩" + "!" 표시 (0.6초)
   │ 4) 미니게임: 초록 바 + 물고기 + 진행 게이지
   ▼
[결과] ──> 도감 갱신 / 최고 기록
   │
   ├─ "계속 낚시" → [낚시 화면]
   └─ "도감" → [도감 화면] → [낚시 화면]
```

### 4.2 조작

| 동작 | 데스크톱 | 모바일 |
|---|---|---|
| 캐스팅 파워 조절 | (자동 왕복) 클릭으로 확정 | 탭 |
| 입질 반응 | 클릭 / Space | 탭 |
| 초록 바 상승 | 마우스 왼쪽 유지 / Space 유지 | 화면 길게 누르기 |
| 초록 바 하강 | 버튼 떼기 | 손 떼기 |
| 일시정지 | ESC / P | 우상단 버튼 |

> 조작은 **"누르고 있으면 뜬다"** 하나로 통일. 설명 없이도 10초 안에 이해되는 것이 목표.

### 4.3 낚시 미니게임 상세 (핵심)

Stardew Valley 방식: 세로 트랙 안에서 **초록 바**를 조작해 **물고기 아이콘**과 겹치게 유지하면 진행 게이지가 차오른다.

```
   ┌──────────────┐
   │  진행 게이지 │  ← 0 ~ 100
   ├──────────────┤
   │              │
   │   ████       │  ← 초록 바 (플레이어)
   │   ████  🐟   │  ← 물고기 (AI)
   │              │
   │              │
   └──────────────┘
```

**규칙**

- 진행 게이지는 **겹칠 때 +22/초**, **벗어날 때 −18/초**.
- 100 도달 → 낚기 성공 / 0 도달 → 실패(놓침).
- 제한 시간 없음 (진행 게이지가 곧 시간). 단, 45초 초과 시 자동 실패로 늘어짐 방지.

**물리 파라미터 (초기값, 튜닝 대상)**

| 파라미터 | 값 | 설명 |
|---|---|---|
| 트랙 높이 | 200 px | 미니게임 영역 |
| 바 높이 | 60 px (난이도 보정 40~70) | 물고기 난이도 ↑ → 바 ↓ |
| 중력 | 900 px/s² | 떼면 내려감 |
| 상승 가속 | 1600 px/s² | 누르면 상승 |
| 최대 속도 | 260 px/s | 조작감 상한 |
| 물고기 기본 속도 | 90 px/s | 난이도 1 기준 |
| 물고기 속도 배율 | 난이도 1~5 → ×0.7 ~ ×2.0 | — |
| 물고기 목표 변경 주기 | 0.35 ~ 1.2초 | 난이도 ↑ → 짧아짐 |
| 물고기 흔들림(노이즈) | ±20 px | 자연스러운 움직임 |

**물고기 AI (의사코드)**

```ts
// 매 프레임
if (timer <= 0) {
  target = clamp(fishY + rand(-90, 90), 0, trackH - fishH);
  timer = lerp(1.2, 0.35, difficulty / 5) * rand(0.8, 1.2);
}
const accel = (target - fishY) * lerp(6, 18, difficulty / 5);
fishVy += accel * dt;
fishVy *= 0.90;                     // 감쇠 → 부드러운 움직임
fishVy += noise(t) * 20 * difficulty;
fishY += fishVy * dt;
```

**바 물리 (의사코드)**

```ts
const holding = input.isDown;
barVy += (holding ? -LIFT_ACCEL : GRAVITY) * dt;
barVy = clamp(barVy, -MAX_VY, MAX_VY);
barY = clamp(barY + barVy * dt, 0, trackH - barH);
// 바닥/천장 충돌 시 속도 0
```

**겹침 판정**

```ts
const overlap = barY < fishY + fishH && fishY < barY + barH;
progress += (overlap ? +22 : -18) * dt;
```

### 4.4 캐스팅 (파워 게이지)

- 좌우로 왕복하는 게이지. 클릭한 지점이 **거리**가 됨.
- 거리는 연출용이지만 **먼 곳 = 희귀 물고기 확률 소폭 증가** (선택적 재미).
- 실패 리스크 없음 → 첫 30초에 "내가 조작하고 있다"는 감각을 주는 역할.

### 4.6 크기와 기록

- 1회 포획 시 **무작위 크기** 결정 (정규분포 느낌, `min + (max-min) * random^1.5`).
- 도감에는 **최대 크기 기록**만 표시. "내 최고 기록" 갱신 시 "NEW!" 연출.
- 결과 화면: 물고기 이름, 크기, 희귀도, "도감 7/12".

### 4.7 도감

- 그리드 4×3 (12칸). 미포획은 실루엣 + `???`.
- 클릭 시 상세: 이름, 크기 범위, 내 최고 기록, 출현 조건, 한 줄 설명.
- 완성 시: "별빛 도감 완성!" 배너 + 특별 배경.

### 4.8 시간대

| 시간대 | 트리거 | 색감 |
|---|---|---|
| 낮 | 기본 | 맑은 하늘, 청록 물 |
| 노을 | 낚시 5회마다 | 주황/분홍 그라데이션 |
| 밤 | 낚시 10회마다 | 남색, 달, 반딧불 파티클 |

> 실제 시계 연동은 하지 않는다. **플레이 횟수 기반**으로 순환시켜 모든 시간대 물고기를 짧은 세션에서 볼 수 있게 한다.

## 5. 아트 디렉션 (아기자기한 Stardew 감성)

### 5.1 원칙

1. **둥글고 부드러운 실루엣** — 각진 픽셀보다 곡선 느낌.
2. **따뜻한 색온도** — 크림색 UI, 노란 햇살, 청록 물.
3. **어두운 갈색 외곽선** (검정 대신 `#5b3a29`) → 부드러운 인상.
4. **제한된 팔레트** — 화면당 24색 이내. 통일감이 곧 완성도.
5. **과한 디테일 금지** — 16×16 타일 기준, 실루엣으로 읽히게.

- 배경 2~3 레이어 **패럴랙스** (구름 > 산 > 나무 > 물).
- 물은 **가로로 흐르는 사인파** + 반짝임 픽셀.
- 낚싯대는 화면 하단 고정, 캐릭터는 손만/실루엣만 보여도 충분.

### 5.4 UI 스타일

- 3px 갈색 테두리 + 크림 배경 + 살짝 둥근 모서리(픽셀 기준 4px 컷).
- 폰트: **갈무리(Galmuri)** 또는 **둥근모꼴+** 계열 픽셀 한글 폰트 (OFL).
- 숫자는 큰 픽셀 비트맵 폰트 사용.
- 버튼: 기본 → 호버 시 밝게 → 누르면 1px 아래로 (눌림감).

### 5.6 사운드

| 사운드 | 설명 |
|---|---|
| cast | 휙- (짧은 노이즈 스윕) |
| splash | 풍덩 (물 튀는 소리) |
| bite | "똑!" 경쾌한 알림 |
| reel | 릴 감는 소리 (미니게임 중 루프, 볼륨 낮게) |
| catch | 반짝 + 상승 아르페지오 |
| fail | 낮게 떨어지는 2음 |
| BGM | 잔잔한 기타/피아노풍 루프 1곡 (또는 생성형) |

> 사운드는 **필수 아님 → 후순위**. 단, `bite`와 `catch`는 손맛에 직결되므로 반드시 넣는다.

## 6. 기술 설계

### 6.1 스택

> ⚠️ **구현 시 변경**: 이 프로젝트를 만든 환경에 Node/npm이 없어, Vite + TypeScript 대신
> **빌드가 필요 없는 바닐라 JS(ES2020) + Canvas 2D** 로 구현했다.
> 파일을 더블클릭하면 바로 실행되고, `index.html`·`js/`·`css/`를 그대로 정적 호스팅에 올리면 배포된다.
> 게임 로직·수치·아키텍처는 아래 설계를 그대로 따른다.

- **HTML + CSS + 바닐라 JS** (클래식 스크립트, 빌드 없음)
- **Canvas 2D** (WebGL 불필요)
- 의존성 0: `howler` 없이 WebAudio 래퍼 직접 구현
- 폰트: Galmuri (CDN, 실패 시 시스템 폰트로 폴백)
- 배포: 폴더째 정적 호스팅 (GitHub Pages / Netlify)

> TypeScript로 옮길 경우, 각 `js/*.js`를 `src/*.ts`로 1:1 대응시키고 `tsc --noEmit`부터 통과시키면 된다.

### 6.3 게임 루프

```ts
const STEP = 1 / 60;
let acc = 0, last = performance.now();

function frame(now: number) {
  acc += Math.min((now - last) / 1000, 0.1); // 탭 전환 시 폭주 방지
  last = now;
  while (acc >= STEP) {
    update(STEP);   // 고정 스텝 → 물리 일관성
    acc -= STEP;
  }
  render();
  requestAnimationFrame(frame);
}
```

### 6.4 상태 머신 (FishingScene)

```ts
type State =
  | { t: 'idle' }
  | { t: 'casting'; power: number; dir: 1 | -1 }
  | { t: 'waiting'; timer: number; biteAt: number }
  | { t: 'bite'; timer: number; fishId: number }
  | { t: 'minigame'; fishId: number; progress: number;
      barY: number; barVy: number; fishY: number; fishVy: number;
      target: number; targetTimer: number }
  | { t: 'result'; success: boolean; fishId: number; size: number };
```

전이:

```
idle ──click──> casting ──click──> waiting
waiting ──timer 0──> bite
bite ──click(0.6s 내)──> minigame
bite ──timeout──> idle (도망 연출)
minigame ──progress 100──> result(success)
minigame ──progress 0 or 45s──> result(fail)
result ──click──> idle
```

```ts
// 480×270 논리 해상도 유지, 화면에 맞춰 정수배 확대

canvas.style.width = `${480 * scale}px`;
canvas.style.height = `${270 * scale}px`;

```

## 13. v0.2 구현 확장 — 판매 · 상점 · 낚싯대

> MVP 완성 후 Stardew Valley에 더 가까워지도록 추가한 경제/장비 시스템.
> 2.3에서 제외했던 **상점 · 판매 · 인벤토리**를 이번 버전에서 구현했다.

### 13.1 확장된 코어 루프

```
낚시 → 물고기 획득(가방) → 상점에서 판매 → 골드 획득
     → 더 좋은 낚싯대 구매/장착 → 더 큰·희귀한 물고기 → 반복
```

### 13.2 가방 · 판매

- 잡은 물고기는 **가방(inventory)** 에 `{ id, size }` 형태로 쌓인다.
- 상점 **물고기 판매** 탭에서 종류별 판매 또는 전체 판매.
- 가격 = `기본가 × (0.75 + 0.5 × 크기비율)` → 클수록 비싸다.
- 가방은 저장되므로 게임을 껐다 켜도 유지된다.

### 13.3 낚싯대 4종

| id | 이름 | 가격 | bar | rare | bite | size |
|---|---|---:|---:|---:|---:|---:|
| `basic` | 나무 낚싯대 | 0 | 1.00 | 1.00 | 1.00 | 0.00 |
| `reinforced` | 강화 낚싯대 | 300 | 1.15 | 1.20 | 1.10 | 0.03 |
| `silver` | 은빛 낚싯대 | 1,200 | 1.30 | 1.45 | 1.20 | 0.06 |
| `gold` | 황금 낚싯대 | 3,200 | 1.45 | 1.80 | 1.30 | 0.10 |

- `bar`: 미니게임 초록 바 높이 배율
- `rare`: ★3 이상 물고기 출현 가중치 배율
- `bite`: 입질 반응 시간 배율 (길수록 여유)
- `size`: 큰 물고기 확률 보정 (크기 난수 지수 감소)
- 구매한 낚싯대는 `ownedRods`에 영구 보관되고, 상점에서 자유롭게 장착 전환.

### 13.4 상점 UI

- **물고기 판매 탭**: 12종 그리드(보유 수/스택 가격), 종류별 상세 패널, 전체 판매
- **낚싯대 탭**: 4종 목록, 성능 문구, 구매/장착/사용 중 상태
- 접근 경로: 타이틀 `[상점]`, 결과 화면 `[상점]`
- 골드 부족 시 토스트 안내, 구매/판매 효과음
